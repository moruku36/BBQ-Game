# BBQ Party

[English](README.md) | [日本語](README.ja.md)

BBQ Party は、ブラウザで遊ぶ60秒のグリルゲームです。食材をえらび、6か所ある網の空きをタップして置き、ちょうどよいタイミングでもう一度タップして回収します。HTML / CSS / JavaScript / Canvas だけの静的ページで、フレームワークもビルドもサーバーも使いません。

## 遊び方

1. `index.html` をブラウザで開きます（静的ファイルサーバーで配信しても動きます）。
2. ニックネームを入れて（なくてもOK・12文字まで）**スタート** を押します。
3. 下のトレイから食材をえらび、空いている網をタップして置きます。
4. 同じ網をもう一度タップすると回収します。網ごとにラベルとタイミングバーが出ます。
5. 60秒たつと結果が出て、同じチャレンジをすぐにやり直せます。

キーボード: 網と食材はすべてボタンです（Tab / Enter / Space）。`1`〜`4` で食材をえらび、`P` か `Esc` で一時停止します。

## ルール

| 食材 | 英語名 | ちょうどよい時間 T | 基本点 |
| --- | --- | --- | --- |
| エビ | Shrimp | 3.0秒 | 80 |
| ソーセージ | Sausage | 3.8秒 | 100 |
| カルビ | Kalbi beef | 4.7秒 | 125 |
| コーン | Corn | 6.0秒 | 160 |

網にのせてからの時間（`age`）と結果:

| 範囲 | 結果 | 点数 |
| --- | --- | --- |
| `age < 0.8T` | RAW（生） | 0 |
| `0.8T <= age < T` | GOOD | 基本点の60% |
| `T <= age <= T + 0.8秒` | PERFECT | 基本点の100% |
| `T + 0.8秒 < age <= 1.5T` | GOOD | 基本点の60% |
| `age > 1.5T` | BURNT（コゲ） | 0 |

- 境界: `0.8T` ちょうどは GOOD、`T` ちょうどは PERFECT、`T + 0.8秒` ちょうどもまだ PERFECT、`1.5T` ちょうどはまだ GOOD です。`1.5T` をこえた瞬間にコゲます。
- コンボ: GOOD か PERFECT を回収すると +1。生を回収するとリセット。コゲたときは、コゲた瞬間に1回だけリセットされ、あとでコゲた食材を片づけても追加のペナルティはありません。
- 倍率: `min(2, 1 + 0.1 × コンボ)`。回収する前のコンボで計算します。
- 人気の食材: 10秒ごとに変わります（6フェーズ、同じ食材が連続することはありません）。各フェーズの最後の3秒間は次の食材が予告されます。その時点で人気の食材を GOOD か PERFECT で回収すると、一律 +50点です。
- 1回の回収の点数: `四捨五入(基本点 × 焼きかげん × 倍率) + ボーナス`。+50 は倍率をかけたあとに足し、倍率はかかりません。
- 置いた直後・回収した直後の0.2秒間、その網はタップを受けつけません。二度押しで2回回収されたり、置いた食材がすぐ外れたりするのを防ぎます。
- 時計が進むのはプレイ中だけです。ページが隠れるとタイマーも食材も止まり、**つづける** を押すまで再開しません。
- 時間切れのとき網に残っている食材は0点で、それ以降は置くことも回収することもできません。

## チャレンジ・記録・共有

- 1回のゲームは「シード」で決まるチャレンジです。シードで人気食材の順番が決まり、**同じチャレンジでもう一度** は同じシードで遊びます。
- チャレンジのリンクは `index.html#v=1&seed=123456789` の形です。入っているのはバージョンとシードだけで、ニックネームは入りません。それ以外の内容がついたリンクは無効として、新しいチャレンジで始まります。
- 共有ボタンは、Web Share API が使えればそれを、なければリンクのコピーを、それも使えなければリンクを文字で表示します。ボタンを押さないかぎり何も共有されません。
- ベストスコア・前回のニックネーム・ミュート設定は、このブラウザの `localStorage` にだけ保存されます。全国ランキング、アカウント、サーバーはありません。保存が使えない環境でもゲームは遊べ、ベストはその回のあいだだけ保持されます。
- ページ自身のファイルを読みこむ以外の通信はしません。

## サウンド・動き・アクセシビリティ

- 短い効果音は Web Audio で鳴らし、最初のタップのあとに初期化します。スピーカーのボタンでミュートできます。
- OS で「視差効果を減らす」を有効にしていると、パーティクル・湯気・お皿に飛ぶアニメーションを出しません。
- 焼きかげんは、色だけでなく文字ラベル・記号・タイミングバーの形でも示します。

## ファイル構成

- `index.html`: ページの構造
- `styles.css`: レイアウトと見た目（スマホ・PC）
- `core.js`: ルール、時間、得点、シードによる順番、リンクの検証、保存、共有（DOMなし）
- `art.js`: 庭・グリル・食材の Canvas 描画
- `app.js`: DOM との接続、描画ループ、サウンド、ライフサイクル
- `tests/`: Node のテスト

## テスト

Node 標準のテストランナーを使います（Node.js 22 で実行）。インストールする依存パッケージはありません。

```
npm test
```

`tests/core.test.js` は時計を差しかえてルールを検証します。`tests/app.test.js` は実際のページのスクリプトを小さな疑似ブラウザ（`tests/helpers/fake-browser.js`）に読みこんで操作します。本物のブラウザでのテストではないため、レイアウト・描画・音は実機のブラウザで確認が必要です。
