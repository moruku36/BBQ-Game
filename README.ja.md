# BBQ Party

[English](README.md) | [日本語](README.ja.md)

BBQ Party は、ブラウザで遊ぶ60秒のグリルゲームです。6種類の食材から1つをえらび、6か所ある網の空きをタップして置き、ちょうどよいタイミングでもう一度タップして回収します。うまく回収を続けるとコンボで倍率が上がり、「いま人気」の食材にはボーナスがつきます。この端末の上位3人のスコアを目標に遊べます。HTML / CSS / JavaScript / Canvas だけの静的ページで、フレームワークもビルドもサーバーも使わず、外部への通信もしません。

[公開版で遊ぶ](https://moruku36.github.io/BBQ-Game/) | [v2検証・画像](BROWSER-VERIFICATION-v2.md) — 本人レビュー・公開済み。

## 遊び方

1. `index.html` をブラウザで開きます（静的ファイルサーバーで配信しても動きます）。
2. ニックネームを入れます（なくてもOK・12文字まで）。音は、始める前にここの **♪ 音の設定** で調整できます。**スタート** を押します。
3. 食材トレイから食材をえらび、空いている網をタップして置きます。
4. 同じ網をもう一度タップすると回収します。網ごとにラベルとタイミングバーが出ます。
5. 60秒たつと結果が出て、同じチャレンジをすぐにやり直せます。

キーボード: 網と食材はすべてボタンです（Tab / Enter / Space）。`1`〜`6` で食材をえらび、`P` か `Esc` で一時停止します。

## バージョン2で変わったこと

- **食材が6種類に。** しいたけ（初心者向け）と厚切りステーキ（上級者向け）を追加しました。どちらも専用の絵・タイミングバー・トレイの表示があります。もとの4種類の時間と点数はバージョン1のままです。
- **PERFECTの幅が食材ごとに。** PERFECTの幅が食材の特徴になり、トレイのボタンに書いてあります。
- **この端末の上位3人。** ニックネームごとのベストをこのブラウザに保存し、上位3人をプレイ中・スタート画面・結果画面に表示します。
- **オリジナルのBGM。** このゲーム用に作った短いループ曲を Web Audio で鳴らします。効果音とBGMは、オン/オフと音量を別々に設定できます。
- **チャレンジのリンクはバージョン2に。** バージョン1のリンクは見分けて説明し、ちがう意味で再生することはありません。
- **そのほかの小さな修正。** 説明文でトレイの位置を言わなくなりました（スマホでは網の下、PCでは網の横にあります）。連打やドラッグでゲームの文字が選択されなくなりました。favicon、`noindex` の指定、Content-Security-Policy を追加しました。

## ルール

| 食材 | 英語名 | ちょうどよい時間 T | 基本点 | PERFECTの幅 P | 特徴 |
| --- | --- | --- | --- | --- | --- |
| エビ | Shrimp | 3.0秒 | 80 | 0.8秒 | 速い |
| ソーセージ | Sausage | 3.8秒 | 100 | 0.8秒 | |
| しいたけ | Shiitake | 4.2秒 | 100 | 1.4秒（いちばん広い） | 初心者向け: 中くらいの速さで失敗しにくい |
| カルビ | Kalbi beef | 4.7秒 | 125 | 0.8秒 | |
| コーン | Corn | 6.0秒 | 160 | 0.8秒 | 遅い |
| 厚切りステーキ | Thick-cut steak | 7.0秒 | 210 | 0.5秒（いちばん狭い） | 上級者向け: いちばん遅く、いちばん高得点 |

バランス: すべてPERFECTで回収した場合、網1か所が1秒あたりにかせぐ点は、ステーキが約30点、もとの4種類が約26〜27点、しいたけが約24点です。ステーキはGOODどまりだと、ほかのどの食材のPERFECTよりも低くなります。つまり、タイミングが正確な人にはステーキ、ふつうの人にはもとの4種類、ゆるめの人にはしいたけが有利で、だれにとっても最強の食材はありません。テストでこれを確認しています。

網にのせてからの時間（`age`）と結果（`P` は上の表の値）:

| 範囲 | 結果 | 点数 |
| --- | --- | --- |
| `age < 0.8T` | RAW（生） | 0 |
| `0.8T <= age < T` | GOOD | 基本点の60% |
| `T <= age <= T + P` | PERFECT | 基本点の100% |
| `T + P < age <= 1.5T` | GOOD | 基本点の60% |
| `age > 1.5T` | BURNT（コゲ） | 0 |

- 境界: `0.8T` ちょうどは GOOD、`T` ちょうどは PERFECT、`T + P` ちょうどもまだ PERFECT、`1.5T` ちょうどはまだ GOOD です。`1.5T` をこえた瞬間にコゲます。
- 1回のゲームは60秒、網は6か所です。
- コンボ: GOOD か PERFECT を回収すると +1。生を回収するとリセット。コゲたときは、コゲた瞬間に1回だけリセットされ、あとでコゲた食材を片づけても追加のペナルティはありません。
- 倍率: `min(2, 1 + 0.1 × コンボ)`。回収する前のコンボで計算します。
- 人気の食材: 10秒ごとに変わります（6フェーズ、同じ食材が連続することはなく、6種類すべてからえらばれます）。各フェーズの最後の3秒間は次の食材が予告されます。その時点で人気の食材を GOOD か PERFECT で回収すると、一律 +50点です。
- 1回の回収の点数: `四捨五入(基本点 × 焼きかげん × 倍率) + ボーナス`。+50 は倍率をかけたあとに足し、倍率はかかりません。
- 置いた直後・回収した直後の0.2秒間、その網はタップを受けつけません。二度押しで2回回収されたり、置いた食材がすぐ外れたりするのを防ぎます。
- 時計が進むのはプレイ中だけです。ページが隠れるとタイマーも食材も止まり、**つづける** を押すまで再開しません。
- 時間切れのとき網に残っている食材は0点で、それ以降は置くことも回収することもできません。

## チャレンジ・リンク・バージョン

- 1回のゲームは「シード」で決まるチャレンジです。シードで人気食材の順番が決まり、**同じチャレンジでもう一度** は同じシードで遊びます。
- チャレンジのリンクは `index.html#v=2&seed=123456789` の形です。入っているのはバージョンとシードだけで、ニックネームは入りません。それ以外の内容がついたリンクは無効として、新しいチャレンジで始まります。
- **バージョン1のリンク（`#v=1&seed=…`）は再生しません。** 食材が6種類になったため、同じシードの番号でも人気の順番が変わり、古いリンクの意味がだまって変わってしまうからです。かわりに、スタート画面でバージョン1のリンクであることを伝え、新しいシードでバージョン2のチャレンジを始めます。古いシードの番号は使い回しません。
- バージョン2の順番はテストで固定しています。今後ルールを変えて順番が変わる場合は、バージョンを上げます。
- 共有ボタンは、Web Share API が使えればそれを、なければリンクのコピーを、それも使えなければリンクを入力欄に表示して手でコピーできるようにします。ボタンを押さないかぎり何も共有されません。

## この端末の上位3人

- ランキングは **この端末のこのブラウザだけ** のものです。`localStorage` に保存され、全国ランキングやオンラインのランキングではありません。アカウントもサーバーもなく、ほかの人のスコアを見ることはできません。
- 同じニックネームは1人として、ベストだけを残します。名前は前後の空白を除いたうえで、入力されたとおりに比べます（大文字と小文字は区別し、Unicode は正規化します）。
- 名前なしで遊んだ場合と、`ゲスト` と入力した場合は、全員共通の「ゲスト」1枠になります。スタート画面と結果画面では、共通の枠であることを表示します。
- 同点のときは、先にその点数をとった人が上です。再読みこみしても順番は変わりません。
- 保存するのは最大20人で、表示するのは上位3人です。記録されるのは1〜99,999の整数だけです。名前は12文字までで、画面には文字としてだけ書きこみます。
- こわれた保存データや手で書きかえたデータは、1件ずつ確認して直します。保存が使えない、または容量がいっぱいの環境でもゲームは遊べます。その場合は結果画面で保存できなかったことを伝え、記録はその回のあいだだけ残ります。
- **バージョン1からの移行:** バージョン1は、名前のないベストスコアを1つだけ保存していました。これを最後のニックネームやほかのだれかの記録にすることはありません。スタート画面に「旧バージョン(v1)の最高」としてランキングとは別に表示し、バージョン1の保存データ自体には手をつけません。バージョン1のミュート設定は、効果音とBGMの両方をオフとして引きつぎます。

## サウンド

- BGMは、このゲーム用に作った8小節のオリジナルのループ曲です（ハ長調、矩形波のメロディと三角波のベース、約17秒）。ブラウザの Web Audio のオシレーターで鳴らします。音声ファイル、他者の曲、ダウンロードは使いません。
- 効果音とBGMは別々に設定できます。**♪ 音の設定** で、それぞれのオン/オフと5段階の音量を変えられ、変えるとそのチャンネルの短い音が鳴ります。設定画面は、スタート画面、一時停止画面、プレイ中のスピーカーボタン（押すと先に一時停止します）から開けます。設定はこの端末に保存されます。
- 音は、タップかキー操作のあとにだけ始まります。BGMが流れるのはプレイ中だけです。一時停止・タブが隠れたとき・ゲーム終了で止まり、**つづける** を押すと止まったところから続き、やり直すと曲の最初から始まります。オーディオコンテキストもループも1つだけで、ループは専用のタイマーではなくゲームの描画ループで進めます。

## 画面・動き・アクセシビリティ

- ゲームはスクロールなしの1画面におさまります。スマホは 360×640 と 390×844 を基準に設計しました。上位3人は細い1行、6種類の食材は3列×2段のトレイで、残りはすべて網に使います。PCでは網が広い列を使い、HUD・上位3人・2列×3段のトレイが横に並びます。
- タップする場所は44px以上です。操作できるものはすべて文字ラベルのあるボタンで、キーボードでも使え、フォーカスは常に見えます。
- 焼きかげんは、色だけでなく文字ラベル・記号・タイミングバーの形でも示します。上位3人の中の自分には矢印と下線がつき、音のスイッチは「オン」「オフ」と文字で示します。
- 連打・ダブルクリック・ドラッグでゲームの文字が選択されることはありません。ニックネームの入力欄と共有リンクの入力欄は、選択してコピーできます。
- OS で「視差効果を減らす」を有効にしていると、パーティクル・湯気・お皿に飛ぶアニメーションを出しません。

## セキュリティと、できないこと

- ページは同じ場所にある自分のファイルだけを読みこみ、ほかの通信はしません。スクリプト・スタイル・アイコンはすべてローカルのファイルで、HTMLにじかに書いたものはありません。
- `Content-Security-Policy` の meta タグでそれを強制しています: `default-src 'none'`、同一オリジンのスクリプト・スタイル・画像のみ、通信なし、プラグインなし、`<base>` なし、フォームの送信先なし。
- ニックネーム、保存データ、リンクの `#` 以降は、信頼できない入力としてあつかいます。長さ・整数の範囲・件数を確認し、画面には `textContent` かフォームの値としてだけ書きこみます。
- `<meta name="robots" content="noindex, nofollow">` で、検索エンジンに掲載しないよう求めています。`robots.txt` でのブロックはしていないので、クローラーはこの指定を読めます。
- **限界。** `noindex` はお願いであり、アクセス制限ではありません。サイトのURL、リポジトリ、ソースは公開されており、URLを知っていればだれでも開けます。GitHub Pages ではこのプロジェクトからHTTPレスポンスヘッダーを設定できないため、HSTS、`X-Frame-Options`、`frame-ancestors` のようなヘッダー専用のCSP指定は、このリポジトリでは設定していません。パスワード、ログイン、非公開モードはありません。
- リポジトリには、ビルド用のワークフロー、シークレット、依存パッケージはありません。

## 技術構成

- `index.html`: ページの構造、CSP と robots の meta タグ、favicon のリンク
- `styles.css`: レイアウトと見た目（スマホ・PC）
- `core.js`: DOMを使わないルール全体。食材の表、焼きかげんの判定、得点、シードによる人気の順番、チャレンジリンクの検証とバージョン、ニックネームの正規化、名前ごとの記録の保存と移行、BGMの譜面とシーケンサー、共有の補助、ゲームの状態管理。時計を外からわたす作りなので、そのまま Node で動きます。
- `art.js`: 庭・グリル・6種類の食材・タイミングバーの Canvas 描画
- `app.js`: DOM との接続、1つだけの描画ループ、Web Audio（コンテキスト1つに効果音用とBGM用のバス）、音の設定画面、画面の切りかえとライフサイクル
- `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`: 自作のアイコン。`tools/make-icons.js` で予備の2ファイルを作り直せます。
- `tests/`: Node のテスト
- `assets/` と `BROWSER-VERIFICATION.md`: バージョン1の画面と実ブラウザ検証の記録（下記）
